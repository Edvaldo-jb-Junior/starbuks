# ☕ Starbucks Landing Page

Uma landing page moderna inspirada na identidade visual da Starbucks, desenvolvida para praticar conceitos de HTML, CSS e JavaScript, com foco em responsividade, 
design atrativo e experiência do usuário.

## 📖 Sobre o Projeto

Este projeto consiste em uma página promocional inspirada na Starbucks, apresentando um layout moderno e responsivo para divulgação de produtos da marca.

O objetivo principal foi aplicar conhecimentos de desenvolvimento front-end, criando uma interface agradável, com elementos visuais que reforçam a identidade
da marca e proporcionam uma boa experiência de navegação em diferentes dispositivos.
